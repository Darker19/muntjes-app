# Muntjes-app · preview

Klikbare preview van de Muntjes-app: een **ouder-app** (telefoon) en een **kind-app** (tablet) die dezelfde gegevens delen.

- Live: https://darker19.github.io/muntjes-app/
- Alleen de ouder-app: `?view=ouder` · alleen de kind-app: `?view=kind`

Alles draait in de browser (HTML, CSS en JavaScript, geen build-stap). De demo-stand wordt in `localStorage` bewaard; met **Demo resetten** begin je opnieuw. Namen en prijzen zijn voorbeelden.

Lokaal bekijken: `python3 -m http.server` en open http://localhost:8000.
